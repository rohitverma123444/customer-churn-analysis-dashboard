# Customer Churn Analysis Dashboard

## Project Overview
This Power BI dashboard analyzes customer churn patterns in a telecom company dataset.

The dashboard helps identify customer behavior, churn trends, contract-wise churn, internet service impact, and payment method analysis.

---

## Key Metrics

- Total Customers: 7043
- Churn Customers: 1869
- Churn Rate: 26.54%
- Average Tenure: 32.37
- Average Monthly Charges: 64.76

---

## Dashboard Features

### Customer Churn Distribution
Visual representation of churned vs retained customers.

### Churn by Gender
Analysis of churn behavior across male and female customers.

### Churn by Contract Type
Comparison of churn among:
- Month-to-Month
- One Year
- Two Year

### Churn by Payment Method
Customer churn analysis based on payment methods.

### Churn by Internet Service
Impact of internet service type on customer churn.

### Interactive Filters
- Contract Type
- Gender
- Internet Service
